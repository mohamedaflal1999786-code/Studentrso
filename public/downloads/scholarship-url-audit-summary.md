## Limitations

This is a preliminary source and destination audit, not a guarantee that all 52 application forms are open or accepting submissions. Automated retrieval returned 403/502 or cache errors for some sites; those are not treated as proof that a website is broken. Some application processes are offline, routed through institutions, UMIS, NSP login, or time-limited calls. The monitoring script checks HTTP status and redirects only; it cannot prove authenticity or semantic match.
